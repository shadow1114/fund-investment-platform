## 2. 定义

### 2.1 Correlation

> **相关系数度量两个收益序列的共同变动程度。**

```
ρ_ij = Cov(R_i, R_j) / (σ_i × σ_j)      ρ_ij ∈ [−1, 1]
```

**无量纲**，便于跨基金比较与直观解读。

### 2.2 Covariance

> **协方差刻画联合变异。**

```
Cov(R_i, R_j) = E[(R_i − μ_i)(R_j − μ_j)]
```

**有量纲**（收益率的二次量），是优化器直接使用的形式。

### 2.3 两者的关系

```
Σ = D × ρ × D

其中 D = diag(σ_1, σ_2, ..., σ_N)  —— 标准差构成的对角矩阵
```

### 2.4 为什么两者都要输出

| 用途 | 使用 |
|---|---|
| **优化求解**（`w'Σw`） | **`Σ`** |
| **展示与诊断** | **`ρ`** —— 无量纲，人可读 |
| 风险归因 | 两者配合 |

> **不得只输出 `Σ`** —— 使用者无法从协方差数值判断"这两只基金相关性高不高"。也**不得只输出 `ρ`** —— 优化器需要 `Σ`，由 `ρ` 与 `σ` 重构会引入两次估计误差的耦合（见 §5.3）。

## 3. 口径一致性 ⚠️

### 3.1 `Σ` 与 `μ` 必须同口径

> 沿用 `01` §6.3、上游 ⑤-B：**同一持有期、同一年化规则、同一收益定义**。

| 口径项 | 要求 |
|---|---|
| **收益定义**（Simple / Log） | 必须与 `02` §3.2 的选择一致 |
| **频率** | 必须与 `μ` 的估计频率一致 |
| **年化规则** | 统一 252 交易日 |
| **Horizon** | 必须等于 Forecast Horizon |
| **Return Basis** | 见 §3.3 |

### 3.2 `Σ` 的对角元必须与 `03` 的波动率估计一致 ⚠️

> **这是一处容易产生不一致的地方。**

```
Σ_ii = σ_i²

但若 03 用 EWMA 估计 σ_i，而本域用样本协方差估计 Σ
    → Σ_ii ≠ σ_i²（EWMA）
    → 同一只基金有两个不同的波动率
    → 下游无法判断该用哪个
```

**要求**：本域与 `03-risk-estimate` **必须使用同一套波动率估计方法**，或明确声明 `Σ` 的对角元是权威值、`03` 的输出仅供展示。

**第一阶段的选择**：**`Σ` 的对角元是权威值**，`03` 的波动率估计必须与之一致（即两者用同一方法与参数）。

> **已定案 · 2026-08-27**：`03-risk-estimate` 与本域**必须采用同一估计方法**，由**同一个 `estimation_policy` 版本**约束，不允许分别配置。
>
> **依据 —— 不一致会使系统自相矛盾**：
>
> ```
> Σ 的对角线元素就是各资产的方差 σ²
>
> 若 03 用 EWMA 估 σ、本域用等权估 Σ
>     → Σ[i][i] ≠ σ_i²
>     → 同一只基金的「波动率」在两处是两个数
>     → 组合风险 √(w'Σw) 与逐基金风险加总的结果无法对账
> ```
>
> **落地方式**：`estimation_policy` 中的 `volatility_method` 与 `covariance_method` 共用同一组参数（加权方式、λ、窗口），**校验规则**在估计产出时断言 `|Σ[i][i] − σ_i²| ≤ 1e-8`（Policy A 的协方差档容差）。
>
> **超差即缺陷，不是可容忍的差异** —— 它意味着两处实现走了不同的代码路径。

### 3.3 超额口径时 `Σ` 必须基于超额收益序列

> **沿用 `02` §5.5.2 的结论。**

```
若 Return Basis = EXCESS：
    μ 基于 (R_fund − R_benchmark)
    Σ 也必须基于 (R_fund − R_benchmark)

若 μ 用超额而 Σ 用绝对
    → μ'w − λ/2·w'Σw 中两项处于不同口径
    → 这是本域最隐蔽的一类错误
```

> **超额口径的 `Σ` 与绝对口径的 `Σ` 数值上可能差异很大** —— 若成分基金共用同一基准，超额序列会剔除共同的市场因子，使相关性显著降低。

## 4. Matrix Requirements

### 4.1 结构性要求

| 要求 | 说明 |
|---|---|
| **方阵** | `N × N` |
| **对称** | `Σ_ij = Σ_ji` |
| **对角元 = 方差** | `Σ_ii = σ_i² ≥ 0` |
| **维度与 `μ`、`w` 一致** | `01` §6.2 |
| **相关矩阵对角元 = 1** | `ρ_ii = 1` |
| **相关矩阵元素 ∈ [−1, 1]** | 超出即计算错误 |

### 4.2 Positive Semi-Definite（半正定）

> **`Σ` 必须半正定：对任意 `w`，`w'Σw ≥ 0`。**

**为什么必须**：

```
w'Σw 是组合方差
    → 方差不可为负
    → 若 Σ 非半正定，存在某个 w 使 w'Σw < 0
    → 优化器会发现一个"负风险"方向并无限利用它
    → 二次规划问题变为非凸，求解失败或给出荒谬解
```

### 4.3 理论上半正定，实际上可能不是 ⚠️

> **样本协方差矩阵在理论上必然半正定，但实际计算中可能失效。**

| 原因 | 说明 |
|---|---|
| **成对删除（Pairwise）缺失处理** | 不同元素用不同的样本期计算 → **破坏半正定性**（§6.2） |
| **数值精度** | 大规模矩阵的浮点累积误差可能使最小特征值为极小负数 |
| **由 `ρ` 与 `σ` 重构** | 若 `ρ` 与 `σ` 来自不同方法或不同窗口，重构的 `Σ` 不保证半正定 |

**处理**：

| 情形 | 处理 |
|---|---|
| 最小特征值为**极小负数**（数值噪声） | 可做**最近半正定投影**（Nearest PSD），且**必须留痕** |
| 最小特征值为**显著负数** | **`ESTIMATION_FAILED`** —— 说明估计方法有结构性问题，不得靠投影掩盖 |

> **已定案 · 2026-08-27**：采用**相对判据**（Policy A §A.5）。
>
> | 判定 | 判据 | 处理 |
> |---|---|---|
> | 数值零 | `\|λ\| ≤ 1e-8 × λ_max` | 置零，视为正常 |
> | 显著负 | `λ < −1e-8 × λ_max` | **须修复**（最近正定投影），并告警 |
>
> **为什么用相对而非绝对阈值**：协方差矩阵的量纲随收益频率变化 —— 日频与年化的元素相差 252 倍，特征值同比例变化。绝对阈值（如 `λ < −1e-10`）在换算频率后会失效，而**相对于 `λ_max` 的判据与量纲无关**。
>
> **1e-8 的来源**：float64 在 N×T 次累加后的相对误差累积上界约在 `√(N·T)·ε` 量级（`ε ≈ 2.2e-16`）。`N=50, T=250` 时约 `2.5e-14`，取 1e-8 是留足四个数量级的保守值 —— 宁可把真实的微小负特征值判为数值零，也不要把数值噪声判为需要修复的结构问题。

### 4.4 半正定 ≠ 可逆

> **两者是不同的性质，容易混淆。**

```
半正定（PSD）：全部特征值 ≥ 0        → 保证 w'Σw ≥ 0
正定（PD）：  全部特征值 > 0        → 保证 Σ 可逆

N 只基金、T 个观测，若 T < N：
    → 样本协方差矩阵的秩 ≤ T < N
    → 必然奇异（有零特征值）
    → 仍是半正定的，但不可逆
```

| 优化目标 | 是否需要可逆 |
|---|---|
| Minimum Volatility（`min w'Σw`，带约束） | **不需要** —— 二次规划只需半正定 |
| 解析解形式（如 `w ∝ Σ⁻¹μ`） | **需要** |

> **第一阶段采用带约束的数值求解**（`06-portfolio/03`），因此半正定即可；但 `T < N` 时矩阵奇异仍会带来严重问题（§7.1）。

### 5.2 Factor-based 第一阶段不实现

> **它需要一个因子收益模型，而本平台的 `04-factor` 是"基金特征因子"而非"收益驱动因子"。**

```
04-factor 的 Factor = 描述基金特征的量化指标（Sharpe、Volatility、Alpha…）
Factor Model 需要的 = 解释收益共同变动的风险因子（市场、规模、价值…）

两者同名但不是同一件事
```

> **若未来引入 Factor Model，须作为新概念回上游登记**，并明确与 `04-factor` 的 `Factor` 的命名区分 —— 否则会产生严重的术语混淆。

> **已定案 · 2026-08-27**：第一阶段**不引入 Factor Model**。
>
> **两个独立的理由，任一都足以否决**：
>
> | # | 理由 |
> |---|---|
> | 1 | **须先回上游登记新概念** —— 风险因子模型（如 Barra 式）是一个新的领域概念，不在上游 10 个 Stage 与术语表内 |
> | 2 | **术语冲突** —— 本平台的 `Factor` 已明确定义为「基金的评价指标」（`04-factor`）。风险模型中的 `Factor` 是「收益的共同驱动源」，两者**同名异义**且都会出现在同一份文档与同一个 API 响应中 |
>
> **第 2 点不是可以靠改名解决的小问题**：即便本域改称 `Risk Factor`，`factor_value`、`factor_version`、`/api/v1/factors` 这些既有标识仍指向评价指标，而新概念会需要一套并行的命名 —— 术语表、表名、端点全都要区分，成本远高于收益。
>
> **不引入的代价**：协方差估计只能靠样本估计 + 收缩，在 `T/N` 较小时精度受限。该代价由 `CC-7` 的 `T/N ≥ 3` 门槛管控 —— **不满足时拒绝产出，而非用一个未经登记的模型补足**。

### 5.3 不建议由 `ρ` 与 `σ` 重构 `Σ`

> **`Σ = D ρ D` 在数学上成立，但作为实现路径有代价。**

```
若 ρ 与 σ 用不同方法/窗口估计
    → 重构的 Σ 混合了两套估计误差
    → 且不保证半正定（§4.3）

若两者用同一方法同一窗口
    → 那就是直接估计 Σ 再导出 ρ，重构是多余的
```

**第一阶段的选择**：**直接估计 `Σ`，再由 `Σ` 导出 `ρ`**（`ρ_ij = Σ_ij / sqrt(Σ_ii Σ_jj)`）。这保证两者天然一致且半正定性得以保持。

### 5.4 Shrinkage 是应对高维问题的主要手段

> **样本协方差在 `N` 接近 `T` 时极不稳定**（§7.1）。收缩把样本矩阵向一个结构化目标拉近：

```
Σ_shrunk = (1 − δ) × Σ_sample + δ × Σ_target
```

| 收缩目标 | 说明 |
|---|---|
| **单位矩阵的倍数** | 假设各基金独立、同波动 |
| **常相关模型** | 假设所有基金对之间相关系数相同 |
| **对角矩阵** | 保留各自方差，假设不相关 |

```
Shrinkage Target    = TBD
Shrinkage Intensity = TBD
```

#### 5.4.1 收缩会系统性压低相关性 ⚠️

> **必须理解收缩的方向性影响。**

```
向单位矩阵或对角矩阵收缩 → 相关性被拉向 0
    → 优化器认为分散化效果比实际更好
    → 与生存偏差（01 §9.2）的影响【同向叠加】
```

**这两个偏差叠加是危险的** —— 两者都使相关性偏低，都使组合看起来比实际更分散。

> **向"常相关模型"收缩不存在这个问题**（它保留平均相关水平），因此在收缩目标的选择上应优先考虑。

> **推荐默认 · 2026-08-27**：收缩目标 = **常相关模型**（Ledoit-Wolf constant correlation），强度用**解析式**，不设固定值。采纳本域原建议。
>
> **依据**：①常相关模型对基金资产比单位矩阵目标更合理 —— 同类基金之间确实存在普遍的正相关，收缩到「零相关」会低估分散化的难度；②解析式避免固定参数（同 `RE2-5` 的理由：最优强度随 T/N 与横截面离散度变化）。
>
> **收缩强度须落库** —— 它是估计结果的一部分，强度接近 1 说明样本估计几乎未被采用，那是数据不足的信号而非正常状态。

## 6. Missing Data

### 6.1 不得简单置零 ⚠️

```
❌ Fund A 有数据、Fund B 缺失 → 令 ρ_AB = 0
   → 这不是"未知"，而是明确宣称"两者无关"
   → 优化器会认为它们能完美分散风险
   → 极度偏好数据缺失的基金
```

**这是本域最危险的默认值选择。**

### 6.2 四种策略及其代价

| 策略 | 做法 | 代价 |
|---|---|---|
| **Pairwise（成对删除）** | 每对基金用各自的重叠期计算 | **破坏半正定性**（§4.3）—— 不同元素基于不同样本 |
| **Complete Case（完整样本）** | 只用所有基金都有数据的时段 | 样本量大幅缩减；**有一只短历史基金就拖累全体** |
| **Imputation（插补）** | 用模型填补缺失 | 引入模型假设；**插补值会人为提高相关性** |
| **Exclude Instrument（剔除）** | 数据不足的基金移出估计范围 | Universe 缩小，但**保证矩阵性质** |

```
Missing Data Strategy = TBD
```

### 6.3 第一阶段倾向 Exclude，理由是矩阵性质 ⚠️

> **Pairwise 看似"充分利用数据"，但它产生的矩阵可能非半正定，直接导致优化失败。**

```
Pairwise 下：
  ρ_AB 用 A、B 的重叠期（36M）
  ρ_AC 用 A、C 的重叠期（12M）
  ρ_BC 用 B、C 的重叠期（12M）
    → 三者不来自同一个联合分布
    → 可能出现 ρ_AB=0.9、ρ_AC=0.9、ρ_BC=−0.9 这类数学上不可能的组合
    → 矩阵非半正定
```

**建议**：观测不足的基金按 `01` §18.1 标 `INSUFFICIENT_DATA` 并移出估计范围（即 Exclude），而非用 Pairwise 强行补齐。

> **已定案 · 2026-08-27**：采用 **Exclude**（成对删除后校验正定性），采纳本域原建议。
>
> **依据**：填充会**制造虚假相关性** ——
>
> ```
> 两只基金各自有缺口，都用「向前填充」补齐
>     → 缺口期间两者的收益都是 0
>     → 这些人为的「共同零收益」被计入相关系数
>     → 两只毫无关系的基金因为在同一天停牌而显得相关
> ```
>
> **成对删除的代价与应对**：不同资产对使用的观测集合不同，结果矩阵**可能非正定**。这正是 §正定性校验存在的理由 —— 检出后做最近正定投影，并记录投影前后的差异。
>
> **投影必须留痕**：投影改变了矩阵，若不记录则无法判断「这个协方差矩阵有多接近原始估计」。差异过大（Frobenius 范数相对变化 > 5%）应触发告警，因为那通常意味着缺失严重到不该产出估计。

## 7. 数据异步与对齐

### 7.1 高维小样本问题 ⚠️

> **这是本域最根本的约束，且它与 Universe 规模直接冲突。**

```
N 只基金 → Σ 有 N(N+1)/2 个独立参数
T 个观测 → 可用信息量约 N × T

N = 100，T = 250（1 年日频）
    → 待估参数 5,050 个
    → 观测点 25,000 个
    → 每个参数平均只有 5 个观测支撑
    → 估计极不稳定
```

**当 `T < N` 时矩阵必然奇异**（§4.4）。

| 缓解手段 | 归属 |
|---|---|
| **增大 `T`**（更长窗口） | 但历史越长，越可能跨越结构性断点 |
| **减小 `N`**（限制 Universe 规模） | `05-fund-evaluation/05` 的 Top-N |
| **提高频率**（日频而非月频） | 但日频有非同步交易问题（§7.2） |
| **Shrinkage** | §5.4 |

> **本域必须在估计前检查 `T` 与 `N` 的关系并预警** —— 这正是 `06-portfolio/03` §13 「候选基金数 ≥ 观测数时求解前应预警，这是估计问题不是求解问题」所指的检查。

> **已定案 · 2026-08-27**：**`T/N ≥ 3` 为最低要求**（低于此拒绝产出），**`T/N < 5` 触发 WARNING**。
>
> **依据**：
>
> ```
> T < N   → 样本协方差矩阵【必然奇异】，秩不足，无法求逆
> T ≈ N   → 矩阵接近奇异，条件数爆炸，优化结果对输入微扰极度敏感
> T ≥ 3N  → 收缩估计（Ledoit-Wolf）可靠性的经验下界
> ```
>
> **T/N 是比值而非绝对值，这一点很重要**：Universe 从 30 只扩到 100 只时，所需样本量按比例增长。**扩大 Universe 不是免费的** —— 它同时提高了对历史长度的要求，而这个约束在只看「有多少年数据」时完全不可见。
>
> **不满足时的处理**：拒绝产出协方差估计，本期优化 `INSUFFICIENT_DATA`。**不降级为对角矩阵**（假设零相关）—— 那会让优化器认为分散化收益无限，产出极度分散的组合，比不优化更糟。

### 7.2 非同步观测

> **不同基金的净值披露不完全同步。**

| 问题 | 说明 |
|---|---|
| **节假日错位** | 跨市场基金的交易日历不同 |
| **NAV 频率不一** | 部分基金非日频披露 |
| **披露时滞不同** | 同一日期的净值，不同基金的 `available_at` 不同 |

**后果**：非同步观测会**系统性低估相关性** —— 两只实际同向变动的基金，若净值分属不同日期，样本相关性被稀释。

### 7.3 频率降低是缓解手段但有代价

```
日频 → 周频/月频
  ✅ 减轻非同步问题
  ❌ 观测数大幅减少 → 加剧 §7.1 的高维小样本问题
```

> **两个问题的缓解方向相反**，这是本域必须做的一个权衡，不存在两全的选择。

> **已定案 · 2026-08-27**：协方差估计频率 = **日频**；**不做非同步交易处理**。
>
> **依据**：非同步交易问题（Epps 效应）源于不同证券在**日内**的成交时点不同，导致高频相关性被低估。**基金按日披露净值，不存在日内成交时点** —— 全部基金的当日净值都对应同一个收盘时点。
>
> **一个真实但不同的问题**：跨市场基金（如 QDII）的净值对应各自市场的收盘，两地收盘存在时差。这**不是** Epps 效应，而是**信息集不同步** —— 处理方式是按 `currency` 分组用各自主日历（`EM-1`），跨组协方差用共同交易日的交集，而非做非同步调整。
>
> **不采用更低频率（周频/月频）的原因**：低频会使 `T` 骤减，与 `CC-7` 的 `T/N ≥ 3` 直接冲突 —— 5 年日频有约 1250 个观测，月频只有 60 个，后者在 `N = 30` 时已不满足门槛。

### 7.4 交易日历对齐规则

> **对齐规则属 `05-estimation-methodology` §6**，本域只声明要求：三条支路（`μ`、`σ`、`Σ`）必须使用**同一套对齐后的收益序列**（`01` §11.1）。

## 8. Matrix Stability

| 问题 | 表现 | 后果 |
|---|---|---|
| **接近奇异** | 最小特征值接近 0 | 条件数极大，优化结果对输入微小变化极度敏感 |
| **奇异** | 存在零特征值 | 不可逆；某些解析方法失效 |
| **极端相关** | 某对 `\|ρ\| → 1` | 该两只基金近乎线性相关，优化器可能给出极端对冲式权重 |
| **条件数过大** | `λ_max / λ_min` 很大 | 数值不稳定 |

### 8.1 条件数是关键诊断量

> **它比"是否半正定"更能反映矩阵的可用性。**

```
条件数 = λ_max / λ_min

条件数很大 → Σ 中包含近乎冗余的方向
           → 优化器在这些方向上的权重几乎不受约束
           → 输入的微小扰动导致权重剧烈变化
```

**要求**：条件数必须作为**输出字段**并纳入校验（`06` §7）。

> **推荐默认 · 2026-08-27**：条件数 **> 1e4 触发 WARNING**，**> 1e6 判 REJECT**。
>
> **依据**：条件数 `κ` 表示求逆时误差的放大倍数。float64 的相对精度约 1e-16，因此：
>
> ```
> κ = 1e4  → 求逆后相对误差约 1e-12   （可接受）
> κ = 1e6  → 求逆后相对误差约 1e-10   （接近 Policy A 的容差上限）
> κ = 1e8  → 求逆后相对误差约 1e-8    （已超出协方差档容差）
> ```
>
> **REJECT 取 1e6 而非 1e8 是留出余量** —— 优化器内部还会做多次矩阵运算，误差继续累积。
>
> **触发 REJECT 时不做「加对角线扰动」的静默修复** —— 那会改变风险结构且不可见。正确处理是缩小 Universe 或延长样本期，即回到 `CC-7` 的 T/N 约束。

### 8.2 极端相关的基金对应被识别并上报

> `|ρ| > 阈值` 的基金对通常意味着**实质上是同一只基金**（如同一基金的不同份额、同一指数的多只跟踪基金）。

**处理**：不自动剔除，但**必须上报** —— 这是 Universe 层去重规则可能失效的信号（`05-fund-evaluation/05` `TBD-FSEL-6`、`06-portfolio/01` §12.1）。

## 10. Matrix Validation

> **校验的执行属 `06-estimation-validation` §7**，本域声明必检项：

| 检查 | 判定 |
|---|---|
| **维度** | 方阵且与 `μ` 一致 |
| **对称性** | `\|Σ_ij − Σ_ji\|` 在容差内 |
| **对角元** | `Σ_ii ≥ 0`；`ρ_ii = 1` |
| **相关系数范围** | `ρ_ij ∈ [−1, 1]` |
| **半正定** | 最小特征值 ≥ −容差 |
| **条件数** | 在阈值内 |
| **缺失值 / NaN / Inf** | 不得存在 |
| **有效观测数** | `T ≥ 最小要求`，且 `T / N` 达标 |

## 11. Edge Cases

| 情形 | 处理 |
|---|---|
| `N = 1` | `Σ` 退化为 `1×1`；相关矩阵无意义 |
| `T < N` | **必然奇异** —— 预警；按 §7.1 缓解或缩减 Universe |
| 某基金 `σ = 0` | 该基金已在 `03` §11.1 判为 `ESTIMATION_FAILED`，不进入本域 |
| 某基金观测不足 | `INSUFFICIENT_DATA` → **Exclude**（§6.3） |
| 最小特征值为极小负数 | 最近半正定投影，**留痕** |
| 最小特征值为显著负数 | **`ESTIMATION_FAILED`**，不得靠投影掩盖 |
| 某对 `\|ρ\| → 1` | 保留但**上报**（§8.2） |
| 条件数超阈值 | `WARNING` 或 `REJECTED`（按 `TBD-CC-9`） |
| 超额口径但部分基金无基准 | 那些基金 `INSUFFICIENT_DATA` → Exclude |
| `μ` 与 `Σ` 的基金集合不一致 | 本域负责对齐并输出 `excluded_instruments`（`01` §6.2） |

## 14. Auditability

> 本域审计总纲见 `01-estimation-framework` §19。本节只列矩阵估计特有的要点。

### 14.1 矩阵调整必须留痕

| 调整 | 必须记录 |
|---|---|
| **最近半正定投影** | 投影前后的最小特征值、调整幅度 |
| **基金剔除** | 逐只的剔除原因 |
| **收缩** | 收缩前的样本矩阵诊断量（至少最小特征值与条件数） |

> **投影是对矩阵的实质性修改** —— 不留痕则事后无法判断优化结果是基于原始估计还是调整后的估计。

### 14.2 诊断量必须与矩阵一同留存

> `min_eigenvalue`、`condition_number`、`effective_observation_count`、`T/N` —— 这些是判断历史决策是否建立在可靠输入上的唯一依据。

**只存矩阵不存诊断量，等于存了结论而没存可信度。**

## 15. Summary

`Σ` 与 `ρ` 是组合优化最关键的输入 —— **一组各自优秀但高度相关的基金，组合起来是糟糕的组合**。

三条口径与结构要求：

- **`Σ` 的对角元是波动率的权威值** —— 本域与 `03` 必须使用同一套估计方法，否则同一基金会有两个不同的波动率
- **超额口径时 `Σ` 也必须基于超额序列** —— `μ` 用超额而 `Σ` 用绝对是本域最隐蔽的错误
- **`instrument_ids` 的顺序是矩阵语义的一部分** —— 顺序错乱时 `w'Σw` 算出的是无意义的数，且不会报错

三处数学性质的澄清：

- **半正定 ≠ 可逆** —— `T < N` 时矩阵必然奇异但仍半正定；带约束的数值求解只需半正定
- **Pairwise 缺失处理会破坏半正定性** —— 不同元素基于不同样本期，可能产生数学上不可能的相关组合；第一阶段建议 Exclude
- **条件数比"是否半正定"更能反映可用性** —— 条件数大意味着存在近乎冗余的方向，优化权重对输入扰动极度敏感

三个方向一致的偏差需要警惕：

- **相关性被系统性低估的三个来源会叠加** —— 生存偏差（`01` §9.2）、非同步观测（§7.2）、向对角/单位矩阵收缩（§5.4.1），三者**同向**，都使组合看起来比实际更分散
- **高维小样本与非同步观测的缓解方向相反** —— 提高频率缓解前者、加剧后者；降低频率反之，不存在两全
- **`ρ = 0` 不是"未知"而是"宣称无关"** —— 缺失时置零会使优化器极度偏好数据缺失的基金

## 16. Decisions

| # | 决策 | 理由 |
|---|---|---|
| D-1 | **同时输出 `Σ` 与 `ρ`** | 前者供求解，后者供人读 |
| D-2 | **直接估计 `Σ`，由 `Σ` 导出 `ρ`** | 避免重构引入两套估计误差且不保证半正定 |
| D-3 | **`Σ` 的对角元是波动率的权威值** | 消除同一基金两个波动率的可能 |
| D-4 | 超额口径时 `Σ` 基于超额序列 | 与 `μ` 同口径 |
| D-5 | **极小负特征值可投影且必须留痕；显著负值判 `ESTIMATION_FAILED`** | 投影不得掩盖结构性问题 |
| D-6 | **Factor-based 相关性第一阶段不实现** | 需要收益驱动因子，与 `04-factor` 的特征因子不是一回事 |
| D-7 | **收缩目标优先评估常相关模型** | 向对角/单位矩阵收缩会与其他偏差同向叠加压低相关性 |
| D-8 | **缺失数据建议 Exclude 而非 Pairwise** | Pairwise 破坏半正定性 |
| D-9 | **缺失时严禁令 `ρ = 0`** | 那是"宣称无关"而非"未知" |
| D-10 | 本域必须在估计前检查 `T` 与 `N` 的关系并预警 | 回应 `06-portfolio/03` §13 的预警要求 |
| D-11 | **条件数是必备输出并纳入校验** | 比半正定更能反映可用性 |
| D-12 | 极端相关的基金对**上报但不自动剔除** | 它是 Universe 去重可能失效的信号 |
| D-13 | **`instrument_ids` 顺序由本域统一交付** | 顺序错乱不会报错，后果隐蔽 |
| D-14 | 诊断量必须与矩阵一同留存 | 只存矩阵等于存了结论没存可信度 |
