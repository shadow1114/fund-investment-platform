## 2. Historical Risk vs Estimated Risk ⚠️

| | **Historical Volatility** | **Expected Volatility** |
|---|---|---|
| 含义 | 过去实际的波动 | 对未来的波动估计 |
| 归属 | `04-factor`（`F-RISK-001`） | **本域** |
| 版本 | `Metric Version` | **`Risk Model Version`** |
| 是否含假设 | 否 | **是** —— 含"波动率可外推"的假设 |

### 2.1 波动率的外推假设比收益的更强，但也更可靠

> **这是一处需要说清的不对称。**

| | 收益 | 波动率 |
|---|---|---|
| 时序自相关 | 弱 —— 历史收益对未来收益的预测力很低 | **强** —— 波动率有明显的聚集性（volatility clustering） |
| 外推的可靠性 | 低 | **相对高** |

```
"过去 3 年年化 12%，未来 1 年也会 12%"     → 可疑
"过去 3 年年化波动 18%，未来 1 年接近 18%"  → 相对可信
```

> **但这不意味着可以省略校验** —— 波动率在市场状态切换时同样会突变（`06` §5）。

## 4. 最大回撤不是可估计的事前风险量 ⚠️

> **沿用 `02-business-requirements` §20.2 与 `06-portfolio/04` §3。**

```
Volatility 事前可估：  σ_p = sqrt(w'Σw)        ✅ 给定 w 与 Σ 即可计算
最大回撤事前不可估：   Future MaxDD(w) ≤ X      ❌ 依赖未来价格路径
```

**最大回撤是路径依赖的量** —— 同样的权重与协方差，不同的价格路径会产生完全不同的回撤。

### 4.1 本域可以产出的与不可产出的

| | 可以 | 不可以 |
|---|---|---|
| **单基金历史最大回撤** | ✅ 属 `04-factor`（`F-RISK-003`） | —— |
| **单基金未来回撤估计** | ❌ 无法从历史序列直接估计 | —— |
| **组合未来回撤估计** | ❌ 需要模拟路径 | —— |
| **回撤代理指标** | 若定义了代理方法则可（§4.2） | —— |

### 4.2 代理方法及其代价

> 若 `06-portfolio/04` `TBD-RB-2` 决定引入事前回撤约束，本域负责提供代理量：

| 代理方法 | 说明 | 代价 |
|---|---|---|
| **历史情景重演** | 用历史极端区间重算该权重下的回撤 | 依赖历史情景的代表性；**只覆盖已发生过的情景** |
| **蒙特卡洛路径分位** | 模拟路径后取回撤分位数 | **引入随机性，须固定种子**；且路径分布假设本身是一个模型选择 |
| **波动率-相关性代理** | 由 `σ_p` 与相关性构造代理指标 | 与真实回撤的关系不稳定，尤其在厚尾情形 |

> **三者都不是"最大回撤的估计"，而是不同的代理量** —— 使用时必须以代理量的名称呈现，不得标为"预期最大回撤"。

> **已定案 · 2026-08-27**：**不提供回撤代理量**；事前的下行风险控制由 **CVaR 约束**承担，回撤保持事后监控。见 `02-business-requirements` §21（`P1-11`）。
>
> **本域的连带结论**：三个候选代理（历史情景重演、蒙特卡洛路径分位数、二阶矩构造）**均不实现**。其中蒙特卡洛路径法还会引入随机性，与可复现性要求冲突（须固定种子且结果对路径模型高度敏感）。
>
> **不得在报告中把 CVaR 表述为「回撤控制」** —— 两者回答不同的问题：CVaR 是「最坏 5% 期间平均亏多少」，回撤是「从峰到谷最多亏多少」。

## 5. Volatility Estimation

### 5.1 Primary Risk Measure

```
Primary Risk Measure = TBD
```

> **本域不自行指定 Volatility 为唯一风险度量。**

虽然均值-方差框架天然使用方差，但组合可能采用 Min CVaR 等其他目标（`06-portfolio/03` §4.1），此时主风险度量不同。

> **推荐默认 · 2026-08-27**：Primary Risk Measure = **年化波动率**；CVaR 作为**约束用的补充度量**。业务方可改。
>
> **依据**：波动率是均值-方差优化的标准输入，**可由 Σ 直接加总到组合层**（`√(w'Σw)`）；CVaR 在组合层不可由个体 CVaR 加总，须用组合收益序列重算（`RI-10`）。两者角色不同 —— 前者进目标函数，后者进约束。

### 5.2 三种估计方法

#### 5.2.1 Historical（Sample）Volatility

```
σ = sqrt( Σ(r_t − r̄)² / (N − 1) ) × sqrt(A)
```

| 参数 | 说明 |
|---|---|
| `N` | 有效观测数 |
| `A` | 年化因子 = **252**（P0 已定案，`05` §9） |
| 分母 | `N − 1`（样本标准差） |

> **分母用 `N − 1` 还是 `N` 必须与 `04-factor/03-factor-definition` 的 `F-RISK-001` 一致**，否则本域的估计与历史 Factor 在同窗口下不可比，交叉核对（`01` §3.1）失去意义。

#### 5.2.2 Exponentially Weighted Volatility（EWMA）

```
σ²_t = (1 − λ) × r²_{t−1} + λ × σ²_{t−1}
```

| 参数 | 说明 | 取值 |
|---|---|---|
| **`λ`（decay factor）** | 越接近 1 越平滑、记忆越长 | `TBD` |

**有效样本长度**：

```
半衰期 = ln(0.5) / ln(λ)
```

> **`λ` 的选择等价于选择一个隐含的观测窗口** —— 这使 EWMA 与 `lookback_window` 参数存在语义重叠，必须明确两者关系（见 §5.3）。

> **推荐默认 · 2026-08-27**：采用 **EWMA，λ = 0.94**（日频）。业务方可改。
>
> **依据**：RiskMetrics 的日频标准值，对应半衰期约 11 个交易日。它在「响应市场状态变化」与「估计稳定性」之间取的平衡已被长期使用检验。
>
> **与 `RI-5` 的联动**：λ = 0.94 时 `lookback ≥ 4 × 11.2 ≈ 45`，但 Policy E 的最小样本量 60 更严，**取 60**。改 λ 时须重新核对哪个约束绑定。

#### 5.2.3 Shrinkage Volatility

> 向横截面均值或同类均值收缩，理由同 `02` §5.6.1。

> **已定案 · 2026-08-27**：**不对单资产波动率做收缩**；收缩只施加于**协方差矩阵**（`04-correlation-covariance` `CC-5`）。
>
> **依据 —— 两者的估计误差量级差一个数量级**：
>
> ```
> 单资产波动率：T 个观测估 1 个参数
> 相关系数矩阵：T 个观测估 N(N−1)/2 个参数
>
> N = 50 时，后者要估 1225 个参数
>     → 误差主要来自相关系数，不是来自单资产波动率
> ```
>
> 对波动率收缩收益甚微，却要引入一个收缩目标与一个强度参数 —— **在误差不是瓶颈的地方增加参数，是净损失**。

### 5.3 EWMA 与固定窗口的参数冲突 ⚠️

> **这是一处容易产生矛盾配置的地方。**

```
Policy 同时声明：
  lookback_window = 36M
  method = EWMA, λ = 0.94

问题：EWMA 的半衰期 ≈ 11 天，远短于 36 个月
    → lookback_window 实际上只是"取多少数据喂给 EWMA"
    → 而非"用多少数据做估计"
    → 两个参数的语义不同，但配置上容易被当作同一件事
```

**要求**：采用 EWMA 时，`lookback_window` 应被理解为**数据供给范围**，实际有效记忆由 `λ` 决定。两者必须在 Policy 中分别说明，且 `lookback_window` 应显著长于半衰期（建议 ≥ 若干倍），否则 EWMA 的递推未充分收敛。

> **已定案 · 2026-08-27**：**`lookback_window ≥ 4 × 半衰期`**。
>
> **依据**：EWMA 权重按 `λ^k` 衰减，半衰期 `h = ln(0.5)/ln(λ)`。在 4 个半衰期之外，累计权重为 `0.5⁴ = 6.25%` ——
>
> ```
> λ = 0.94（日频）→ 半衰期 ≈ 11.2 天 → lookback ≥ 45 个交易日
> ```
>
> **截断误差 6.25% 是可接受的上界**：它作用于方差估计，对标准差的影响约为其一半（3%），已在 `EV-2` 的稳定性告警阈值之内。
>
> **同时须满足 Policy E 的最小样本量 60** —— 两个约束取严者。日频 λ=0.94 时最小样本量是绑定约束（60 > 45）。

### 5.4 波动率的时间尺度转换

```
σ_annual = σ_period × sqrt(A)
```

> **这一转换依赖"收益独立同分布"的假设**。在存在自相关时（如平滑净值的基金），`sqrt` 法则会**系统性低估**长期波动率。

**第一阶段的处理**：沿用 `sqrt` 法则（与 `04-factor` 一致），但对**明显存在净值平滑的基金**（如部分固收类）标注该局限。

> **已定案 · 2026-08-27**：第一阶段**不做自相关调整**。
>
> **依据**：Newey-West 需要选择带宽（lag length），而带宽的选择本身有多种规则（Andrews 自动选择、`T^{1/3}` 经验式等），**引入的参数不确定性可能大于它修正的偏差**。
>
> **偏差量级的判断**：基金日频收益的一阶自相关通常在 ±0.05 以内（除非持有大量低流动性资产）。按 `σ²_adj ≈ σ²(1 + 2ρ)` 估算，`ρ = 0.05` 对年化波动率的影响约 5% 相对量 —— 可观测但**不改变排序**，而波动率在本系统中主要用于**相对比较**（Peer Group 内分位）与优化输入。
>
> **例外须单独提出**：若将来引入持有非流动性资产的基金类别（如部分 FOF 或另类），其净值平滑效应会使自相关显著为正，届时须重新评估。这一评估的触发条件应写入 `estimation_policy`。

## 6. Downside Risk

### 6.1 定义

```
σ_d = sqrt( Σ min(r_t − threshold, 0)² / (N − 1) ) × sqrt(A)
```

### 6.2 阈值的来源是一个必须解决的问题 ⚠️

> **提示词建议用 `MAR` 作为 downside threshold。这在本域会产生一个结构性问题。**

```
MAR 属 05-fund-evaluation 的 Evaluation Policy
    → 它按 fund_category × currency 配置
    → 依赖 MAR 的量会随 Evaluation Policy Version 变化

若本域的 Expected Downside Volatility 使用 MAR：
    → σ_d 会随【评价政策】变化
    → 但 σ_d 是要喂给优化器的风险输入
    → 意味着"改变评价标准"会改变"组合优化的风险输入"
    → 评价与优化两条链路被耦合
```

### 6.3 本域的处理：定义独立的 Downside Threshold

> **本域使用独立的 `downside_threshold`，不复用 `MAR`。**

| | **MAR** | **Downside Threshold**（本域） |
|---|---|---|
| 用途 | 单基金**评价**的下行阈值 | 组合**优化输入**的下行阈值 |
| 归属 | `05-fund-evaluation` 的 Evaluation Policy | **本域**的 Risk Estimation Policy |
| 版本 | `Evaluation Policy Version` | **`Risk Model Version`** |
| 配置粒度 | 按 `fund_category` × `currency` | 按估计政策，全 Universe 统一 |

**理由**：

| # | 理由 |
|---|---|
| 1 | **解耦评价与优化** —— 改变评价标准不应改变优化的风险输入 |
| 2 | **保持 Universe 内可比** —— MAR 按类别差异化会使同一 Universe 内的 `σ_d` 不在同一标尺（与 `05-fund-evaluation` 的 Peer Group 内 MAR 一致性要求是同一类问题，但这里的样本集是 Universe 而非 Peer Group） |
| 3 | **版本归属清晰** —— 风险输入的变更应升 `Risk Model Version` |

```
Downside Threshold = TBD（取值待定，但归属与版本已定）
```

> **两者数值上可以相同，但必须是独立字段**（沿用上游 §5.5.1 对 `R_f` 与 `MAR` 的同一原则）。

#### 6.3.1 MAR 定案不改变本域的独立性（v1.1 说明）

> **MAR 已于 2026-08-27 定案为三模式、第一版默认 `ZERO`**（`05-fund-evaluation/01` §16.3、`TBD-resolution.md` Policy ②）。**本域的 `Downside Threshold` 仍独立**，`TBD-RI-7` 不随之关闭。

| | `MAR` | `Downside Threshold` |
|---|---|---|
| 用途 | **单基金评价** —— 算 Sortino / Downside Volatility | **组合优化输入** —— 算下行风险估计 |
| 归属 | `05-fund-evaluation`（Evaluation Policy） | **本域**（Estimation Policy） |
| 版本 | `evaluation_policy` | `estimation_policy` |
| 消费方 | Factor 层 | 优化器 |

> **为什么不复用**：MAR 变更是**评价标准变更**（「我们对好基金的定义变了」），`Downside Threshold` 变更是**估计参数变更**（「我们对下行风险的度量口径变了」）。两者的审批路径、影响范围、回归验证范围都不同。复用会让一次评价标准调整**意外改变全部组合的风险估计**，进而改变优化结果 —— 而这个连锁反应在配置层完全不可见。

> **可以取同值，且第一版很可能就取同值（0）** —— 但那是两次独立的决策恰好一致，不是一次决策被两处使用。

> **已定案 · 2026-08-27**：`Downside Threshold` = **0**（与 `mar_policy = ZERO` 同值，但**独立配置**）。
>
> **依据**：与 MAR 选 `ZERO` 的理由相同 —— 最容易解释、不依赖外部数据、不产生额外 PIT 问题、跨资产类别一致（`04-factor/03` §2.2.4）。
>
> **「同值」与「同一个字段」是两件事**（§6.3.1 已论证）：
>
> ```
> 两者当前都是 0，但归属不同版本：
>     MAR                → evaluation_policy
>     Downside Threshold → estimation_policy
>
> 若将来 MAR 改为 RISK_FREE，Downside Threshold 【不】随之改变
>     → 那是两次独立的决策，只是第一版恰好一致
> ```
>
> **配置层必须是两个字段**。合并会让一次评价标准调整意外改变全部组合的风险估计，而这个连锁反应在配置层完全不可见。

### 6.4 四个"阈值/基准"概念的完整区分

> **沿用 `06-portfolio/03` §3 并补充本域新增的一项：**

| 概念 | 含义 | 归属 |
|---|---|---|
| **`R_f`** | 市场无风险利率（观测值） | `03-data` |
| **`MAR`** | 单基金评价的最低可接受收益（评价标准） | `05-fund-evaluation` |
| **`Downside Threshold`** | 风险估计的下行阈值（估计参数） | **本域** |
| **`Minimum Portfolio Return`** | 组合最低收益要求（优化约束） | `06-portfolio/03` |

> **四者可以取相同数值，但在数据模型、配置模型与版本归属上必须独立。**

## 7. VaR 与 CVaR

### 7.1 定义

```
VaR_α   = −percentile(r, 1 − α)             α 置信水平
CVaR_α  = −E[ r | r ≤ percentile(r, 1 − α) ]
```

> **CVaR 度量超过 VaR 阈值之后的期望损失** —— 它刻画尾部的深度，而 VaR 只刻画尾部的入口。

### 7.2 三种 VaR 方法

| 方法 | 说明 | 假设 |
|---|---|---|
| **Historical VaR** | 直接取历史收益分位 | **不假设分布**；但只覆盖已发生的情景 |
| **Parametric VaR** | 假设正态：`VaR = −(μ + z_α σ)` | **假设正态** —— 基金收益普遍厚尾，会低估尾部风险 |
| **Monte Carlo VaR** | 模拟路径 | 分布假设 + 随机性（须固定种子） |

```
VaR Method       = TBD
Confidence Level = TBD
```

> **推荐默认 · 2026-08-27**：VaR 方法 = **历史模拟**（同 `RI-10`），置信水平 = **95%**。业务方可改。
>
> **依据**：95% 与上游指标清单（`02-business-requirements` §5.2.1「VaR 95%、CVaR 95%」）一致。**改用 99% 时须同步把最小样本量提到 1000**（Policy E）—— 这一联动容易被忽略：提高置信水平不只是换个分位数，它对样本量的要求是数量级的变化。

### 7.3 Parametric VaR 的正态假设会低估尾部 ⚠️

> **这不是理论顾虑。** 基金收益的峰度普遍高于正态分布（`04-factor` 已定义 `F-STAB` 类的 Skewness / Kurtosis）。

```
正态假设下 99% VaR ≈ 2.33σ
实际厚尾分布下的 99% 分位往往显著更深
    → Parametric VaR 系统性低估极端损失
```

**若采用 Parametric VaR，必须同时监控实际峰度**，并在峰度显著偏离正态时标 `WARNING`。

### 7.4 Historical VaR 对样本量的要求 ⚠️

```
估计 99% 分位 → 尾部只有 1% 的样本
  N = 250 个观测 → 尾部仅 2–3 个点
  → 分位估计极不稳定，单个极端值就会改变结果
```

**要求**：VaR/CVaR 的最小样本量要求**显著高于**波动率。沿用 `04-factor/03-factor-definition` 对 `F-RISK-004/005` 的 `Min Obs ≥ 100` 要求，并按置信水平提高。

> **已定案 · 2026-08-27**：见 `TBD-resolution-2.md` Policy E。
>
> | 置信水平 | 最小观测数 |
> |---|---|
> | 95% VaR / CVaR | **250** |
> | 99% VaR / CVaR | **1000** |
>
> **为什么远高于波动率的 60** —— **VaR 是分位数而非矩**：
>
> ```
> 波动率：全部 T 个观测都参与估计
> 95% VaR：只由尾部约 5% 的观测决定
>     → T = 250 时，尾部只有约 12 个点
>     → CVaR 是这 12 个点的平均，每个点的权重都很大
> ```
>
> 用 60 个观测算 95% CVaR，等于用 3 个观测点的平均代表尾部 —— 单个极端值就能主导结果。**这不是精度问题，是估计量根本不稳定。**

### 7.5 CVaR 比 VaR 更稳定但更依赖尾部样本

| | VaR | CVaR |
|---|---|---|
| 数学性质 | **不满足次可加性** —— 不是一致性风险度量 | **满足次可加性** —— 一致性风险度量 |
| 组合层可加性 | 组合 VaR 可能大于成分 VaR 之和 | 不会 |
| 对尾部样本的依赖 | 只用分位点 | **用全部超出分位的样本** |

> **CVaR 的次可加性正是 Min CVaR 可表达为凸 LP 的基础**（Rockafellar-Uryasev，`06-portfolio/03` §4.1）。

### 7.6 组合层 VaR / CVaR 的计算方法（回应 `TBD-RB-1`）

> **`06-portfolio/04` §2.1 明确点名此项待本域确认。**

**核心事实**：组合层 VaR / CVaR **不能由基金层 VaR / CVaR 加权得到**。

```
组合 VaR ≠ Σ w_i × VaR_i
    → VaR 不满足加权关系
    → 必须按【组合收益序列】重新计算
```

**本域提供的方法**：

| 方法 | 做法 | 前提 |
|---|---|---|
| **A：组合收益序列重算（推荐）** | 用历史成分收益按当前权重构造组合收益序列 `r_p,t = Σ w_i r_i,t`，再对该序列求分位 | 需要成分收益的**同期对齐序列**（`04` §6） |
| B：参数法 | 由 `σ_p = sqrt(w'Σw)` 与正态假设推出 | 继承 §7.3 的低估问题 |
| C：蒙特卡洛 | 由 `μ`、`Σ` 模拟 | 须固定种子；分布假设是模型选择 |

> **方法 A 有一个容易被忽略的性质**：它用**当前权重**回溯历史，得到的是"若当时就持有这个组合会怎样"，而非"历史上这个组合实际的表现"。这是正确的做法（风险估计需要的正是前者），但必须在呈现时说清，避免被误读为历史业绩。

**归属**：组合层 VaR / CVaR **依赖 `w`，因此属 `06-portfolio/03`（⑦-R）计算**；本域提供**方法定义与所需的对齐收益序列**。

> **已定案 · 2026-08-27**：采用 **§7.6 推荐的方法（历史模拟法）** —— 用组合权重重构历史组合收益序列，再取其分位数。
>
> **依据**：
>
> | 方法 | 问题 |
> |---|---|
> | 参数法（正态假设） | 基金收益**厚尾**，正态假设会系统性**低估**尾部风险 —— 而 VaR 存在的意义正是度量尾部 |
> | 蒙特卡洛 | 引入随机性（须固定种子），且结果依赖路径模型的选择 |
> | **历史模拟**（已采纳） | 不依赖分布假设；代价是只能反映样本期内出现过的情形 |
>
> **历史模拟的已知局限须在报告中声明**：它无法表达样本期外的风险。**这个局限是诚实的** —— 参数法看似能外推，实际是用一个已知错误的分布假设在外推。
>
> **与 `06-portfolio/04` `RB-1` 是同一决策**，两处不得分别配置。

## 9. 极端值处理对风险估计的影响 ⚠️

> **与 `02` §8.2 是同一条原则，但在风险估计中后果更严重。**

```
剔除极端收益 → 波动率下降、VaR 变浅、CVaR 变浅
    → 风险被系统性低估
    → 优化器认为可以承担更大仓位
```

**尾部样本正是风险估计最需要的部分。** 因此：

| 类型 | 处理 |
|---|---|
| **结构性异常**（数据错误） | 修正或剔除，且必须留痕 |
| **统计性异常**（真实极端行情） | **保留**，标 `WARNING` |

> **不得为了"估计更稳定"而剔除真实的极端值** —— 那不是稳定，是失真。

## 11. Risk Estimate Failure

| 情形 | 处理 |
|---|---|
| **观测不足** | `INSUFFICIENT_DATA` |
| **尾部样本不足**（VaR/CVaR） | `INSUFFICIENT_DATA`，即使总观测数达标 |
| **缺失观测过多** | 按 `05` §7；超阈值 → `INSUFFICIENT_DATA` |
| **极端波动** | 保留但标 `WARNING`（§9） |
| **`σ = 0`** | **`ESTIMATION_FAILED`** —— 零波动通常意味着净值未更新（数据问题），见 §11.1 |
| **非平稳** | 第一阶段不自动检测；窗口跨越转型点标 `WARNING`（`01` §18.2） |
| **数值失败** | `ESTIMATION_FAILED`，须告警 |

### 11.1 `σ = 0` 必须判为失败而非有效估计 ⚠️

> 沿用 `04-factor/03-factor-definition` §10 的边界条件原则。

```
σ = 0 意味着窗口内净值完全无波动
    → 几乎必然是数据问题（净值未更新、停牌）
    → 若作为有效估计传给优化器：
       · Σ 的对角元为 0 → 矩阵奇异
       · 最小方差优化会把全部权重压给这只"零风险"基金
```

**处理**：`ESTIMATION_FAILED` 并告警，该基金移出本次估计范围。

## 12. Edge Cases

> §11 列出的是**失败情形**；本节列出**非失败但需特殊处理**的边界。

| 情形 | 处理 |
|---|---|
| 窗口内收益全部为正 | `σ_d = 0`（无下行偏离）→ **`INSUFFICIENT_DATA`** 而非 `σ_d = 0`；理由同 `04-factor/03-factor-definition` §10 的"好消息型除零" |
| 窗口内无损失超过 VaR 阈值 | `CVaR` 无样本可平均 → `INSUFFICIENT_DATA` |
| 尾部样本恰好只有 1 个 | VaR 可算但极不稳定 → `WARNING`，并输出 `tail_observation_count` |
| `σ` 极小但非零 | 保留；但下游 `Σ` 的条件数会恶化（`04` §8.1），须在矩阵层预警 |
| 基金历史长于窗口但中间有长期暂停 | 有效观测数按去除暂停期计；不足则 `INSUFFICIENT_DATA` |
| 同一基金不同 Share Class 的风险估计接近 | **正常** —— 它们持有同一组合，费率差异只影响收益不显著影响波动 |
| Horizon 与 `μ` 不一致 | **配置错误，阻断**（`01` §6.3） |
| Downside Threshold 未配置 | 下行风险类估计 `INSUFFICIENT_DATA`，**不得默认为 0**（沿用 `R_f` 缺失不补 0 的同一原则） |

### 12.1 `σ_d = 0` 的处理与 `σ = 0` 不同

> **两者都是"零"，但含义完全相反。**

```
σ = 0    → 净值无波动 → 几乎必然是数据问题 → ESTIMATION_FAILED（§11.1）
σ_d = 0  → 窗口内从未下跌 → 可能是真实的优秀表现 → INSUFFICIENT_DATA
```

> 后者标 `INSUFFICIENT_DATA` 而非 `FAILED`，是因为它不是错误；但也不能作为有效估计传给优化器——`σ_d = 0` 会使任何以下行风险为分母的量趋于无穷。

## 17. Summary

本域产出**事前风险**（逐基金、不依赖权重），依赖 `w` 的量属 `06-portfolio/03`。

三条概念澄清：

- **波动率的外推假设比收益的更可靠** —— 波动率有聚集性、时序自相关强；但这不意味着可以省略校验
- **最大回撤不是可估计的事前风险量** —— 三种代理方法都不是"最大回撤的估计"，使用时必须以代理量的名称呈现
- **VaR 不满足次可加性，CVaR 满足** —— 后者的一致性正是 Min CVaR 可表达为凸 LP 的基础

三处本域必须做的独立设计：

- **本域定义独立的 `Downside Threshold`，不复用 `MAR`** —— 否则改变评价标准会改变优化的风险输入，使评价与优化两条链路耦合；两者数值可同但必须是独立字段
- **组合层 VaR/CVaR 不能由基金层加权**（回应 `06-portfolio` `TBD-RB-1`）—— 须按组合收益序列重算，且方法 A 是"若当时持有这个组合会怎样"，不是历史业绩
- **EWMA 的 `λ` 与 `lookback_window` 语义不同** —— 前者决定有效记忆，后者只是数据供给范围；配置上容易被当作同一件事

三处容易低估的陷阱：

- **静默剔除极端值会系统性低估风险** —— 尾部样本正是风险估计最需要的部分，剔除不是稳定而是失真
- **Historical VaR 在 99% 置信下尾部只有 2–3 个点** —— 最小样本量要求必须显著高于波动率
- **`σ = 0` 必须判为失败** —— 否则 `Σ` 对角元为零使矩阵奇异，且最小方差优化会把全部权重压给这只"零风险"基金
